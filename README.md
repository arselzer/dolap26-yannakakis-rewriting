# Yannakakis SQL rewriter

The [Scala rewriter](query-rewriter/) and [benchmarks](benchmarks/) are here.
Run `./setup.sh` to check the benchmark files and build the rewriter.

To recompute Table 11 and Figure 9 of the paper from the recorded runtimes
(no database needed; requires `pandas`, `numpy` and `matplotlib`), open
[`reproduce_paper_results.ipynb`](reproduce_paper_results.ipynb).
